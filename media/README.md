# 3M Media

This folder is reserved for GitHub and portfolio media.

## Needed assets

1. `3m-interface.png` — screenshot of the prototype interface.
2. `emotion-detection.png` — screenshot of webcam/emotion classification running with safe demo input.
3. `recommendation-flow.png` — diagram of face input → emotion classification → song recommendation.
4. `3m-demo.gif` — optional short loop of the local prototype if dependencies can be restored.

## Capture guidance

Do not use a real person’s face in public media without consent. If possible, use a test image, synthetic face, or cropped/non-identifying demo capture.

Because this is an older project, a clear architecture diagram may be more reliable than a live GIF until dependencies are modernized.
